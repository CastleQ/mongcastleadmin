## 새로 알게 된 것 · 함정

- **배포와 SQL 실행 사이에는 시간 차가 있다.** 아래 '내가 틀린 것'의 사고 원인.
  → CLAUDE.md 절대 규칙 0-1 로 **옮김**. 처리 방법은 `src/lib/missing-column.ts`.
- **PostgREST 는 모르는 칸이 하나 있으면 목록 조회를 통째로 거절한다** (`42703 column does not exist`).
  한 칸 때문에 화면이 0건이 된다. 빈 배열이 와도 "자료가 없다"는 뜻이 아니다.
- **`info_sections`·`templates`·`settings` 는 AI 가 읽을 수 없다** (관리자 전용 RLS, anon 으로는 빈 배열).
  단, 요금표는 `public_settings` 창으로, 예약 날짜·패키지는 `public_reservations` 창으로 읽힌다.
  자료가 멀쩡한지 확인할 때 이 두 창이 유용하다.
- **BGG XML API(`xmlapi2`)는 이제 401** 이다. `api.geekdo.com/api/geekitems` 를 쓴다 (스킬에 이미 적혀 있었다).
  보드라이프 게임 페이지의 meta description 에 `이름(원제) … N세 이상 N-N명이 N분` 이 그대로 들어 있어
  한글명만 알 때 제일 빠르다.
- **`git mv` 로 폴더를 옮긴 커밋은 체리픽에서 충돌한다** (원본 파일이 대상 가지에 없을 때 `DU`).

  빼고 싶은 것만 되돌리는 쪽이 깔끔했다.
