## 결정한 것 (왜 그렇게 정했나)

### 사장님이 정한 것
- **미정산 = 권리금으로 돌려받을 매입.** 보드게임·집기는 사업 접을 때 권리금으로 회수하므로
  이번 장사의 손익에 넣지 않는다. 소모품(머리끈·생수)은 정산완료.
  → `docs/운영규칙.md` 로 옮김. 코드에서 실제로 그렇게 동작하는지 확인함(`sales.ts` 의 모든 집계가 `settled` 만 더함)
- **게임 분류는 BGG보다 사장님 판단 우선.** 윙스팬만 전략, 카탄 포함 나머지 10종은 파티
- **스위치 게임 14종 전부 한국어판**
- **달무티는 10분** — BGG는 60분이라 적지만 실제 한 판은 10분
- **SQL은 사장님이 직접 실행.** AI에게 DB 쓰기 권한(service_role 키)을 주지 않기로 함.
  그 키는 고객 연락처가 든 거래 표까지 열고, 이 프로젝트는 구글캘린더의 남이 쓴 글을 읽어오므로
  거기 악의적인 지시가 섞일 여지가 있다 → **읽기만 가능한 지금 상태 유지**
- **"여러 건 한 번에 추가" 화면은 만들지 않음** (제안했으나 사장님이 됐다고 함)
- 세션 기록을 남기기로 함. 공개 저장소지만 **지금은 개인정보·보안을 따지지 않고 투명하게** 적는다

## 새로 알게 된 것 · 함정

> 규칙으로 굳힌 것은 CLAUDE.md·스킬로 **옮김**. 여기엔 왜 그런지만 남긴다.

1. **터치는 `click`보다 `pointerleave`가 먼저 온다** (크롬에서 실측).
   `pointerdown → pointerup → pointerout → pointerleave → mousedown → mouseup → click`
   그래서 click 시점에 "팝오버가 떠 있나"를 보면 이미 닫힌 뒤라 영원히 첫 터치로 본다.
   → 판정을 pointerdown 으로 옮김. `src/lib/tap.ts` + 테스트 5개. **CLAUDE.md 규칙 10으로 옮김**
2. **Supabase SQL 편집기는 문장마다 따로 저장한다** → 임시 표를 쓰면 다음 문장에서 사라진다.
   → 넣기·고치기·지우기를 `with` 한 문장으로. **`write-sql` 스킬로 옮김**
3. **anon 키로 `games` 는 읽을 수 있다**(공개 읽기). `ledger`·`customers`·`settings` 는 못 읽는다.
   게임 중복 확인·반영 여부 확인에 실제로 썼다. **`write-sql` 스킬로 옮김**
4. **`npm run dev` 가 CLAUDE.md 끝에 Next.js 안내 블록을 덧붙인다.**
   → `next.config.ts` 에 `agentRules: false` 로 껐다
5. **한국닌텐도 스토어 이미지는 외부에서 못 쓴다** (봇 차단, 202 빈 응답).
   한국판 패키지 사진을 쓰려면 사장님이 실물을 찍어 올리는 수밖에 없다. **`운영규칙.md` 로 옮김**
6. **`pkill -f "next dev"` 는 자기 셸까지 죽인다**(exit 144). 명령을 나눠 쓴다
7. 구글캘린더 일정에서 **종일 일정을 '전일'로 단정하면 안 된다** — 사장님이 낮·밤·전일을 모두
   종일로 적고 계셔서 2/3가 틀린다. 실제 캘린더를 읽어보고 알았다
