## 새로 알게 된 것 · 함정

- 되돌리기 보관용 표(`create table ... as select`)를 만들면 Supabase 가 **RLS 경고**를 띄운다.
  손님용 anon 키는 브라우저에 그대로 있으므로 **"Run and enable RLS"** 가 맞다. SQL 편집기는 표 주인
  권한이라 잠가도 되돌리기가 된다. → 이제 SQL 안에 `alter table ... enable row level security;` 를
  같이 넣어 경고가 안 뜨게 한다.
- **줄 바꿔치기 SQL 은 재실행 안전을 따로 챙겨야 한다.** '주차 1·2순위 → 1~4순위' 가 두 번 돌리니
  6줄이 됐다. `and body not like '%주차 4순위%'` 같은 조건을 붙여 막았다.
- 컨테이너가 새로 뜨면 **검증용 `pgtest` 계정이 사라지고**, 로컬 가지가 원격보다 뒤처져 있을 수 있다
  (`useradd -u 30033 -m pgtest`, 그리고 push 전에 `git fetch` → `git rebase origin/<가지>`).
