## 예약취소 기능 (f558ffd)
손님이 예약을 취소했을 때 **거래를 지우지 않고 '취소' 표시만** 한다. 되돌리기 버튼으로 언제든 원래대로.

- DB: `ledger.cancelled` 칸(참/거짓, 기본 거짓) — `supabase/done/ledger-cancel.sql` (이미 실행됨. 2026-11-13 조회해 칸이 있는 것 확인, 취소된 건은 아직 0건)
- 같은 SQL 이 손님용 달력 창 `public_reservations` 에서 취소 건을 빼 **빈자리로 보이게** 한다
- 취소된 건이 빠지는 곳: 거래 합계(`ledger/page.tsx`), 매출현황 분석(`sales/page.tsx`), 손님용 예약현황(`reservations/page.tsx`), 구글캘린더(`calendar-push.ts` `isExportable` — 취소하면 구글 일정이 지워지고, 되돌리면 다시 생김), 고객 방문 수·금액(`customers.ts`)
- 남는 곳: 거래 목록(회색 줄긋기 + '예약취소' 딱지), 고객 정보, 예약 검색, 내보내기(`api/export` 에 칸 포함)
- 버튼: `ledger/cancel-button.tsx` → 서버 동작 `setCancelled`(`ledger/actions.ts`). 구글 반영은 `after` 로 화면을 넘긴 뒤에(작업 규칙 13)
- 판정 함수 한 곳: `lib/ledger.ts` `isActive`. 테스트: `customers.test.ts`·`calendar-push.test.ts`
- 왜 지우지 않나: 절대 규칙 0(기록은 사장님 것) + 노쇼·취소가 잦은 손님을 고객 관리에서 알아보려면 기록이 남아야 한다
