# 운영 규칙 — 사장님이 정한 것

여기엔 **사장님이 정했고 코드·DB 어디에도 안 적혀 있는 규칙**만 둔다.
가격처럼 DB·코드에 원본이 있는 것은 여기 베끼지 않는다 (베끼면 금방 어긋난다).

| 찾는 것 | 원본은 어디 |
|---|---|
| 요금표(낮·밤·전일, 밤샘, 보증금, 기준인원) | Supabase `settings.prices` → 화면은 admin **가격 정보** |
| 지인 20% 할인, 보증금 규칙, 채널 수수료율 | `src/lib/prices.ts`, `src/lib/pricing.ts`, `src/lib/ledger.ts` |
| 특장점·주차·플랫폼 등록 현황 | admin **몽캐슬파티룸 정보** (`info_sections`) |

---

## 1. 정산 스위치의 뜻 (중요 — 손익이 달라진다)

거래 한 줄의 **정산** 스위치는 "돈을 주고받았나"가 아니라 **"이번 장사 손익에 넣을 것인가"** 로 쓴다.

| | 정산 | 이유 |
|---|---|---|
| **매입 — 파티룸에 남는 물건** (보드게임, 스위치 게임, 셔플러, 집기) | **미정산** | 사업을 접을 때 **권리금으로 돌려받을 돈**이라, 이번 장사의 비용으로 치지 않는다 |
| **매입 — 써서 없어지는 소모품** (생수, 머리끈, 간식) | **정산완료** | 그달 비용이 맞다 |
| **매출 — 돈이 들어온 예약** | 정산완료 | |
| **매출 — 아직 안 들어온 예약** | 미정산 | 매출현황의 "예약 포함" 보기가 **오늘 이후 건만** 끌어다 보여준다 |

나중에 권리금을 정리할 때 미정산 매입의 스위치를 켜면 그때부터 손익에 들어온다.

**이대로 동작하는 것을 코드에서 확인했다** (2026-10-12): `src/lib/sales.ts`의 모든 집계가
`settled`인 행만 더하고, "예약 포함" 보기가 끌어오는 미정산 행도 `kind === "매출"`뿐이라
미정산 매입은 어느 쪽에도 들어가지 않는다.

## 2. 매입 항목(category) 나누는 법

- `집기구매` — 파티룸에 **남는** 물건 (게임, 셔플러, 가구, 기기)
- `기타` — **써서 없어지는** 소모품 (생수, 간식, 소모 비품)
- `월세기타`, `광고비` — 고정비. 매출현황에서 따로 센다

이름 칸(`customer_name`)에 **품명을 짧게** 넣는다. 거래 표에서 바로 보이는 칸이다.
영수증에 적힌 긴 상품명은 메모(`note`)에 넣는다.

## 3. 보유 게임

- **종류(`kind`)**: `보드게임` / `머더미스터리` / `스위치게임`
- **보유 게임 탭 순서**: 파티게임 → 전략게임 → 테마게임 → 머더미스터리 → 닌텐도 스위치 (2026-10-12 "그 외" 없앰)
- **탭 나누기**: `추상전략`(아발론)은 전략게임 탭, `마피아`·`테마게임`·장르 없음은 테마게임 탭.
  게임 관리의 장르 칸은 보드게임일 때 이 다섯 개(파티·전략·추상전략·마피아·테마게임)에서만 고른다. 늘리려면 `src/lib/games.ts` 의 `BOARD_CATEGORIES`
  카드에는 원래 장르 글자가 그대로 보인다 (통일하지 않음 — 사장님 결정)
- **분류(`category`)는 사장님 판단이 BGG보다 우선한다.** 2026-10-11 지시: 윙스팬만 `전략`,
  나머지 10종(카탄 포함)은 전부 `파티`
- **스위치 게임 14종은 전부 한국어판** (`language = '한국어'`)
- **스위치 게임의 인원은 "본체 1대 + TV 1대" 기준.** 로컬통신·온라인 인원은 소개에 따로 적는다
- 공개 페이지 노출: 보드게임·스위치게임은 이미지가 없어도 보이고, **머더미스터리만 이미지가 있어야** 보인다
- 소개(`synopsis`)는 손님이 보는 글, 메모(`note`)는 관리자만 본다

## 4. 사진

- 게임 사진은 BGG·GameStop·아마존 주소를 그대로 가리킨다. 저쪽 사이트가 바뀌면 깨진다
- **한국닌텐도 스토어 사진은 못 쓴다** — 외부에서 불러가는 것을 막아 둠
- 확실한 방법은 **사장님이 실물을 찍어** 게임 관리 화면에서 올리는 것. 우리 저장공간에 들어가 안 깨진다

## 5. 일하는 방식

- **SQL은 사장님이 Supabase SQL Editor에서 직접 실행한다.** AI는 파일을 만들어 전달만 한다
- AI가 DB에 직접 쓰려면 모든 보안을 무시하는 마스터 키가 필요한데, 그 키를 작업환경에 두면
  고객 연락처가 든 거래 표까지 열린다. 그래서 두지 않기로 했다 (2026-10-12 검토)
- AI는 **게임 목록은 읽을 수 있다**(공개). 거래·고객·설정은 못 읽는다(관리자 전용)
- 배포는 검증이 끝나면 **AI가 알아서** 한다 (사장님 상시 지시)
