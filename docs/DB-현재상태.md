# DB 현재 상태 — 저장소만 봐서는 알 수 없는 것

**이 파일이 있는 이유.** 응대 템플릿·몽캐슬파티룸 정보는 **관리자만 읽을 수 있어 AI가 못 봅니다**
(CLAUDE.md 'AI가 못 읽는 것'). 거기에 무엇이 들어 있는지, 되돌릴 수 있는 보관본이 어디 있는지가
대화창에만 남아 있으면 **새 대화에서 통째로 사라집니다.** 그래서 비밀값은 빼고 **구조와 상태만** 적습니다.

마지막 확인: **2026-11-12**

> **2026-11-12부터 AI가 관리자 키로 모든 표를 직접 읽을 수 있다**(CLAUDE.md '관리자 키'). 이 파일과 DB가 다르면 **DB가 맞다.**
> 같은 날 정보에 `9. 몽캐슬 청소 가이드 🧹` 섹션을 추가했다(부록은 순서 11로).

---

## 1. 되돌리기용 보관 표 (DB에 남아 있음 — 함부로 지우지 말 것)

본문을 덮어쓰는 SQL을 돌릴 때마다 옛 내용을 통째로 복사해 둔 표입니다. **쓰레기가 아닙니다.**
사장님이 "이제 됐다"고 하시기 전에는 **지우지 않습니다**(절대 규칙 0).

| 보관 표 | 무엇의 옛 내용 | 만든 날 |
|---|---|---|
| `info_backup_20251025` | 정보 › **인근 주차 안내** 섹션 본문 | 2026-10-25 |
| `info_backup_core_20251025` | 정보 › **핵심 정보** 섹션 본문(주차 줄 바꾸기 전) | 2026-10-25 |
| `templates_backup_20261104` | **입금안내 2개** 문구 본문(새 틀로 바꾸기 전) | 2026-11-04 |
| `templates_backup_20261111` | **예약 확정 문자** 본문(출입 칸 옮기기 전) | 2026-11-11 |

되돌리는 법 (해당 표만, 사장님 확인 뒤에):
```sql
-- 정보 섹션
update info_sections s set body = b.body, updated_at = now() from <보관표> b where s.id = b.id;
-- 응대 템플릿
update templates   t set body = b.body                  from <보관표> b where t.id = b.id;
```
다 확인되어 치울 때: `drop table if exists <보관표>;` (서두르지 않아도 됩니다)

## 2. 저장소에 없는 SQL (비밀이 들어 있어 git 제외 — 전부 **실행 완료**)

파일 자체는 임시 공간에만 있다 사라집니다. **무엇을 왜 넣었는지**만 남깁니다.
다시 필요하면 아래 설명만 보고 같은 SQL을 새로 만들 수 있습니다.

| 날짜 | 한 일 | 상태 |
|---|---|---|
| 10-25 | 정보 › 인근 주차 안내 섹션 본문을 새 주차 정보로 교체 | 실행됨 |
| 10-25 | 정보 › 핵심 정보의 **주차 줄만** 2줄 → 4줄로 (주민센터 무료가 1순위) | 실행됨 |
| 11-04 | 입금안내 2개 문구 본문을 새 틀로 교체 | 실행됨 |
| 11-04 | 예약 확정 문자에 출입 안내 칸 추가 → 기본값을 `{{출입 비밀번호}}` 자리표로 연결 | 실행됨 |
| 11-11 | 예약 확정 문자 본문 교체 — 출입 칸을 맨 아래에서 **5번째 줄 제자리**로 | 실행됨 |

## 3. 지금 각 문구에 들어 있는 칸 (대괄호 = 보낼 때 채우는 칸)

본문 전체는 못 읽으니, **어떤 칸이 있는지**만 적습니다. 문구를 고칠 때 이 표를 먼저 봅니다.

| 문구 | 들어 있는 칸 | 메모 |
|---|---|---|
| **예약 확인 후 입금안내** | `[고객명]` `[날짜]` `[패키지]` `[총액]` | 별도컨택·계좌이체용. 총액에 청소보증금이 자동으로 더해짐 |
| **플랫폼결제 확인 후 보증금 입금안내** | `[고객명]` `[플랫폼]` `[날짜]` `[패키지]` `[이용료]` `[추가옵션]` | 총액은 `{{보증금}}`으로 고정(이용료는 플랫폼에서 결제 완료). `[이용료]`가 있어 패키지 줄에는 금액이 안 들어감 |
| **예약 확정 문자** | `[출입 비밀번호={{출입 비밀번호}}]` (5번째 줄) | 기본값은 **핵심 정보 표**에서 끌어옴. 비우면 "연락주시면 안내해드릴께요" 문구가 나감 |
| **타 플랫폼 중복 예약 취소 안내** | `[고객명]` `[플랫폼]` `[날짜]` | |

`{{중괄호}}`는 보낼 때 자동으로 채워지는 값입니다 — 요금표(`{{보증금}}` 등)와
핵심 정보 표의 모든 줄(`{{출입 비밀번호}}` `{{화장실}}` `{{와이파이}}` …).

## 4. 보유 게임 목록은 여기 두지 않는다

게임은 계속 늘고 줄어서 **적어두면 바로 옛 숫자가 됩니다.** 대신 `games` 표는
**로그인 없이 읽을 수 있어** AI가 언제든 지금 목록을 직접 확인할 수 있습니다
(방법은 스킬 `add-games` 0단계). 그래서 목록 대신 **읽는 법**만 남깁니다.

```bash
curl -s "$NEXT_PUBLIC_SUPABASE_URL/rest/v1/games?select=id,kind,name,category,qty&order=name" \
  -H "apikey: $NEXT_PUBLIC_SUPABASE_ANON_KEY" -H "Authorization: Bearer $NEXT_PUBLIC_SUPABASE_ANON_KEY"
```

2026-11-12 기준 **110종** (보드게임 81 · 머더미스터리 15 · 스위치게임 14).
※ 2026-10-13에 넣은 **칠교놀이는 지금 없습니다** — 사장님이 지우신 것으로 보입니다.
   세션 기록에는 "4종 추가"로 남아 있으니, 숫자가 안 맞으면 이 때문입니다.

## 이 파일을 고쳐야 할 때

- 본문을 덮어쓰는 SQL을 돌렸다 → 1·2번 표에 한 줄 추가
- 문구에 칸을 넣거나 뺐다 → 3번 표 고치기
- 보관 표를 지웠다 → 1번 표에서 줄 빼기
